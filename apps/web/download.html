Installation guides

How to install

Pick your device. Every guide is 30 seconds — no account needed until you unlock.

Android — APK sideload

Works on Android 8.0+ · No Play Store needed

  1. Download the APK — tap Download APK above. Chrome will warn “unknown file type” — tap Download anyway.
  2. Open the file from your notification or Downloads. If prompted, tap Allow from this source (or enable Install unknown apps for your browser).
  3. Tap Install → Open. calibrEAT opens on the welcome screen — tap Enter your license code when you’re ready to unlock.
  4. Lost the prompt? — open Files → Downloads → calibrEAT.apk and tap again.
Safety note: “Unknown sources” just means outside the Play Store. The APK is signed by us — Android lets you review permissions before you tap Install. You can turn the permission off after.

iPhone & iPad — IPA

iOS 15+ · TestFlight beta → App Store at launch

  1. During beta: install Apple’s TestFlight (free, App Store), then open our invite link — tap Accept → Install.
  2. At launch: open the App Store, search calibrEAT → tap Get. Same one-time license, no IAP on Apple.
  3. Open calibrEAT. On first launch it shows the welcome screen — keep it installed and you’ll keep every update automatically.
Your license is cross-platform — the same code you buy on the website works on Android, iOS and Mac. Enter it once per device on the welcome screen.

Mac — Intel & Apple Silicon (unified)

macOS 12+ · One universal download for both Intel and M1/M2/M3/M4

  1. Download the Mac build (single .dmg — works on Intel and Apple Silicon, macOS picks the right binary).
  2. Open the .dmg → drag calibrEAT to Applications. Eject the disk image.
  3. First open: right-click calibrEAT → Open (Gatekeeper shows “downloaded from the internet” once) → Open. Next time, just double-click.
  4. App opens on the welcome screen — enter your lifetime code to unlock.
Not sure if you’re Intel or Silicon? You don’t need to be — the same download runs natively on both. Apple → About This Mac will say Chip (Apple Silicon) or Processor (Intel), but either way the steps are identical. If macOS says “can’t verify developer”, use the right-click → Open trick — no Terminal needed.
